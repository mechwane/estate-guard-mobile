- Build uses @lovable.dev/vite-tanstack-config (worker output), never SPA/static mode — static publishing removes server functions and webhooks, breaking payments.
- Payment settlement: bank accounts (Paystack subaccounts) live in settlement_accounts and are created only by super admins via server functions; collections/bill runs reference one and checkout resolves collection → bill run → estate default. Why: estates must never type their own payout account, and each estate's money must be separable.
- Paystack verification clears a bill with the provider's requested_amount (fees passed to the customer are not a mismatch) through applyVerifiedPayment in paystack.server.ts, shared by callback, webhook and the resident's on-load sync. Why: one authoritative path, and bills still clear if the resident closes the page.
